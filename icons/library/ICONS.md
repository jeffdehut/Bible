Open `index.html` in this folder to browse them all.

## Visual style guide

Taken from the code: index.html (`:root`, the dark-theme blocks and the icon CSS), nav.js, share.js, themes.js, sketch.js, ui.js and the page templates.

### Grid and construction

- **24 × 24 grid.** Almost every icon has `viewBox="0 0 24 24"` and keeps its drawing inside roughly 2–22 units, with a margin of about 2 to 3 units. The exceptions: the sticky-note marks and the in-text sketch pencil use a 20 × 20 grid, the timeline legend swatches are 22 × 12, and the app icon is 512 × 512.
- **Outline icons drawn with strokes.** The SVG has `fill="none" stroke="currentColor"`, and the drawing is plain `<path>`, `<circle>`, `<rect>` and `<ellipse>` elements with no fills, gradients or shadows. share.js puts it this way: “Drawn on a 24-unit square as strokes, one SVG path each, so the same shapes serve the page (as SVG), its canvas and these pictures (as Path2D).” themes.js: “Each is drawn on a 24-unit square in strokes, like the site’s other icons, and takes the color of the text around it.”
- **Round caps and round joins** (`stroke-linecap="round" stroke-linejoin="round"`) on nearly all of them. A few simple shapes, such as the close X, search, menu and zoom icons, set only the round cap.
- **Single weight.** Each icon uses one stroke width throughout. There are no thick/thin contrasts and no detail strokes at a second weight.
- **Few filled shapes, kept on purpose:** the media controls (play, pause, previous and next verse, `fill="currentColor"`), the solid bookmark sign in the chapter picker, and the sticky-note marks (pale highlight fill with a darker outline). The exports keep these filled.
- **Dots** are drawn as zero-length strokes (`h.01` or `v.1`), so they come out round at any size. You can see this in the i of “about”, the dot of a question mark and the bullets of the chronicle list.

### Color

- **currentColor everywhere.** An icon takes the color of the text or button around it. In the exported files that becomes the light-theme ink **#161b26**, so they show up in any viewer. To recolor one, change `stroke` (or `fill` for the filled ones).
- **Palette (light theme, index.html `:root`):** paper `--bg` #fbfaf7, surface #ffffff, **ink** #161b26, muted #5b6475, faint #8d95a4, line #e4e2db. The accent is **lapis** #2646a1 (soft #e7ecf8), with **gold** #8a640b (soft #f6eedb) beside it. The app icon itself is lapis #2646a1 with a light gold #f3d27a book.

  - Place pins in the verse panel are lapis.
  - Web badges draw the icon in the paper color on a disc of the group’s color, or in the group color inside a ring.

### Dark mode

The icons themselves don’t change in dark mode. Because they use currentColor, they follow the dark tokens: ink #e9ecf3 on paper #0d111b and surface #131a28, lapis #9db3ff, gold #e2bd5c (also `#e2bd5c` for the Explore menu icons), muted #a3acbd.

- Bible-section icons and badges switch to their lighter second color (`--c2`).
- Highlight fills become translucent tints, and their inks get lighter. For example, the yellow ink goes to #e8bd4f.

Dark mode follows the system setting unless `data-theme` forces light or dark. The seasonal themes (ui.js `SEASONS`: spring, summer, autumn, winter, each with light and dark) replace paper, ink, lapis and gold, so icons pick up the season’s accent. For example, spring’s lapis is #3b7a4b and autumn’s is #a3461d.

| 22 px | Menu button on secondary pages |
| 20 px | Reader buttons (`.icon`), sketch toolbar, listening and auto-scroll controls, support heart |
| 18 px | Picker search field, color-theme swatches, card close and tuck buttons on the visual pages |

| 0.9 em | Emoji marks in running text, so they scale with the reading size |

### Overall feel

The icons are calm, plain, single-weight line drawings that sit quietly beside the serif reading text (Frank Ruhl Libre; the UI is set in Libre Franklin) on a warm off-white paper. The look is scholarly and paper-like.

They are concrete pictures rather than abstract symbols: tablets for the Law, a lamp for wisdom, a dove for the Spirit, a crown for kings, an ant for work. The geometry is simple, with rounded ends and generous space.

Color comes from the surrounding text and from small colored tiles or discs, never from the icon itself. That way the whole set works in light, dark and every seasonal theme without change.

## Not exported (not SVG icons)

- **Study markings** (the boxes, underlines, washes and small signs ♔ ↻ § ◷ ∴ ⇄ → described in MARKINGS.md) are drawn with CSS text decoration, borders, backgrounds and Unicode characters, not SVG.
- **Charts and maps** (`<svg id="chart">`, `#map`, `#tree`, `#overview`, the word-map stage, scripts/chart.py output) are data drawings generated at run time, not icons.
- **Sketches** (sketch.js `picture()`) are the reader’s own drawings.
- The **“✕”** text character in the secondary pages’ menu header is a text glyph.

## How to use / regenerate

**Using the files.** Each file is a standalone SVG with `xmlns`, its original `viewBox` and `width`/`height` equal to the viewBox (24 × 24 for most), so it opens in any browser or editor at its natural size and scales freely.

- **Stroke settings.** Stroke width, caps and joins are exactly as in the code at the primary place of use. Where an icon is drawn at different widths in different places, the table says so.
- **Color.** `currentColor` has been replaced by the ink color `#161b26`. To match the app in another color, set `stroke` (and `fill` for the filled icons) to `currentColor` again, or to any color. CSS variables were replaced by their light-theme values from index.html `:root`.
- **Inline use.** To use an icon inline like the app does, copy its inner elements into `<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">`. Use stroke-width 1.8 for menu and theme icons and 1.9 for emoji marks.
- **Duplicates.** Identical drawings are kept once. The ↗ rows in a family’s table point to a file kept in another family’s folder.
- **Colored copies.** The files in `06-bible-sections/colored/` and `07-connections-web/colored/` are the same icons stroked in each group’s light-mode color.

**Regenerating.** The export was made by three small scripts kept outside this folder, in `tools/` next to it. They only read the repository.

- `collect.py` finds every literal `<svg>…</svg>` in index.html, nav.js, sketch.js and scripts/templates/*.html. It also reads the icon tables: nav.js `ICON` and `MENU`, share.js `ICONS`, themes.js, index.html `EMOJI_ICONS`, `PK_MARK`, `SEASON_INFO`, `guide()`, the ink tabs, `STICKY_SVG`, the `.has-note` data URI, history.html `GLYPH`, and the visual-book/visual-letters `ICONS` and `IC`. It then groups the icons by geometry: paths are converted to absolute coordinates and split into subpaths, so equal drawings written differently still match.
- `manifest.py` gives each unique drawing its family, file name, name and description.
- `build.py` writes the SVGs, this catalogue (usage labels for the themes and timeline icons are read from psalms.html, scripts/wisdom.py, history.html and scripts/webpages.py) and `index.html`.

To regenerate, run `python3 -I tools/build.py` from the folder that holds `tools/` and `BibleData-icons/`. If an icon is added to the app, the build stops and names any drawing that is not in the manifest. Add a line for it to `manifest.py` and run the build again.
